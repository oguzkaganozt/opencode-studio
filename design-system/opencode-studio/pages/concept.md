# Page override — Concept viewer

Overrides MASTER for Concept studio viewer.

## Intent
Concept cards + brief document. Violet accent on rails only. Host shell stays locked.

## Surfaces
- Home: Concepts grid, status badge, optional moodboard thumb
- Project: intent, context, constraints, musts, chosen direction, moodboard grid, review findings, BRIEF.md when frozen
- Empty/error: dashed EmptyState with short recovery copy
- Agent → `concept`

## Chrome rules
- Accent `#7c3aed` / dark `#a78bfa` via `--osc-accent-concept`
- No handoff chips to other studios
